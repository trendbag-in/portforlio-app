Type direction

Four ways the marketing site could speak

The same hero, kicker, buttons, card and price set four ways and rendered at 2x, so the comparison is of actual drawn type rather than font names. Every face here is on Google Fonts, so any of them ships without a licence conversation.

Why this came up. The live stack pairs Plus Jakarta Sans — a safe geometric UI sans — with JetBrains Mono, which is a code editor typeface. I brought that mono over from the pitch deck without questioning whether a font designed for reading diffs belongs on a fashion brand. It does not. The three alternatives all replace it with letterspaced small caps, which is what print fashion actually uses for credits and kickers.

Option A

Bodoni Moda · Karla

Editorial didone

Recommended

The masthead face of fashion publishing. Bodoni is a true didone — hairline serifs, extreme thick-to-thin contrast — and the italic on actually does the work a colour change was doing before. Karla underneath is a warm, slightly quirky grotesque that keeps the body from feeling starchy.

Works because

  • Reads unmistakably as fashion, not as SaaS
  • The italic gives you emphasis without leaning on terracotta
  • Karla's small caps replace the code-mono for labels

Costs you

  • Didones need generous sizes and tight tracking to work — it will look weak below 40px
  • Furthest from the product app's voice
Option B

Fraunces · Figtree

Soft serif warmth

Fraunces is a variable 'soft serif' with wonk and optical-size axes — it can be pushed warm and characterful rather than severe. It suits the warm paper canvas better than a cold didone, and reads more approachable, more India-first-D2C than Paris-runway.

Works because

  • Warmest of the three; sits naturally on #F7F6F4
  • Variable axes let you tune personality without swapping fonts
  • Distinctive without being costume

Costs you

  • The wonk axis is polarising at large sizes
  • Less 'luxury' than the didone if that is the positioning
Option C

Instrument Serif · Instrument Sans

Modern fashion grotesque

A matched superfamily, so the display and the body are drawn to agree. Instrument Serif is high-contrast and current — the face doing a lot of work on new fashion and beauty sites right now — and the sans is a clean, quiet companion that will not fight it.

Works because

  • Cohesive by construction — one designer, two faces
  • The most contemporary of the three
  • Lightest to implement; sans handles every UI role

Costs you

  • Currently fashionable, which means it will date fastest
  • Serif has only one weight — less range for hierarchy
Live now

Plus Jakarta Sans · JetBrains Mono

The current stack

What is on the site today. Plus Jakarta Sans is the app's UI face and JetBrains Mono is a code editor font — I carried it over from the pitch deck, which was itself built by a developer. It is competent and it is consistent with the product, but nothing about it says fashion.

Works because

  • Exactly matches the mobile app's single-family rule
  • Mono numerals genuinely help prices and stats scan

Costs you

  • Reads as a developer tool, not a fashion brand
  • Geometric sans + coding mono is the default AI/startup pairing
  • No display face means no editorial voice anywhere
