How it was done

  • Resolved pre-paint. An inline script in index.html reads localStorage and stamps data-theme before CSS applies — a React effect would render one frame on the wrong canvas.
  • data-theme="dark" is also the static default on the html element, so the page is dark even with JS disabled.
  • The toggle still writes to localStorage, so a light preference survives reloads.

The typographic catch

  • Light type on a dark ground optically thins, and a didone is mostly hairline — Bodoni at 700 started to break up on #0B0B0A.
  • Dark mode carries the display face to weight 800 and eases tracking to 0 so the counters stay open.
  • The accent also shifts on dark, from #C2410C to #FF7A4D — the darker fill goes muddy against near-black.
